# Trekking Management Application - MAD I

This project is developed as part of IITM BS Degree Modern Application Development I course.

## Project Description

The Trekking Management Application is a web application for managing trekking activities between Admin, Trek Staff, and Trekkers.

## Roles

### Admin
- Manage treks
- Approve trek staff
- Assign staff to treks
- Manage users and bookings

### Trek Staff
- View assigned treks
- Update trek details
- Manage participants

### User
- Search available treks
- Book treks
- View booking history

## Technologies Used

- Flask
- SQLite
- Jinja2 Templates
- HTML
- CSS
- Bootstrap
